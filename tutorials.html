Setup Guides

Follow these step-by-step tutorials to get Sniperr running on your Cronus Zen. Each section covers a specific feature — work through them in order for best results.

0 Loading the Script

▼

Before anything else, you need to flash the Sniperr .gpc file onto your Cronus Zen. This only takes a couple of minutes.

  1. Open Zen Studio on your PC
  2. Go to Slot 1 — make sure it's empty (right-click → Clear if needed)
  3. Drag and drop the Sniperr .gpc file into Slot 1
  4. Click Program at the bottom to flash it to your Zen
  5. Wait for the confirmation — you're good to go
Tip: Always clear any old scripts from the slot before loading Sniperr. This avoids conflicts and ensures clean operation.

Connecting Your Controller + Zen

How you plug in depends on your platform:

  • Xbox: Connect your Xbox controller to the Zen's top USB port. Connect the Zen to your console with the bottom USB port. That's it — Xbox auto-pairs.
  • PS5: Use a standard PS5 controller (not Edge). Connect controller → Zen top port, Zen → console bottom port via USB. See the PS5 Bypass section below for the required extra step.
  • PS4: Same as PS5 but no bypass needed. Controller top port, Zen to console bottom port.
  • PC: Connect Zen to PC via USB. Connect controller to Zen's top port. Set output protocol to PS5 in Zen Studio for auto-detect to work.

1 PS5 Bypass

▼

If you're on PS5, there's an essential bypass step you must do every time you boot up. Without this, the Zen won't authenticate properly.

  1. Make sure your PS5 firmware is fully updated (latest version)
  2. Use a standard DualSense controller (not the Edge model)
  3. On your PS5, go to Settings → Accessories → Controllers
  4. Set Communication Method to USB Cable
  5. Plug your controller into the Zen, then Zen into the console
  6. Hold the Right D-Pad for 10 seconds — wait for the LED to confirm
PS5 Settings Required: Vibration Intensity → STRONG | Trigger Effect → STRONG | Communication Method → USB Cable

7 2-Touch Mod

▼

The 2-Touch system lets you quickly select weapons, barrel stabilizers, and optics using two-button combos. Instead of scrolling through menus, press two buttons simultaneously to instantly swap configurations.

Recommended bindings:

  • Assault Rifle profile: Reload + Up Arrow
  • SMG profile: Reload + Down Arrow
  • Optics swap: Reload + Right Arrow
  • Barrel swap: Reload + Left Arrow
  • Reset to default: Reload + Touchpad
Tip: Practice these combos in the firing range until they become muscle memory. Once you've got them down, weapon switching mid-fight becomes effortless.

8 Sensitivity & Anti-Recoil

▼

The core of what makes Sniperr so effective — properly dialed sensitivity and anti-recoil settings. There are two modes available:

  • Normal Sensitivity: Uses Apex's standard sensitivity sliders. Simpler to configure and works great for most players.
  • Advanced Sensitivity: Uses per-optic ADS multipliers and response curve tweaks. More granular but harder to dial in.
Recommendation: We highly recommend using Normal sensitivity unless you have a specific reason for advanced. Normal provides the most consistent anti-recoil performance across all weapons.

10 Auto Detect (PS5 & PC Only)

▼

Auto Detect uses your controller's adaptive triggers and vibration feedback to automatically identify which weapon you're holding — no manual switching required.

Xbox users: Auto Detect does not work on Xbox because Xbox controllers lack adaptive trigger hardware. Xbox users should use the 2-Touch system instead.

In-game settings required:

  • Deadzone for L2/R2 → None
  • Adaptive Triggers → On
  • Vibration → Default

Zen-side settings:

  • Game Rumble → On
  • Auto Resync → PS5
  • Auto Detect → Always On

PC-specific notes:

  • In Zen Studio, set Output Protocol to PS5
  • Close Zen Studio completely after programming (it can interfere)
  • Turn off Steam Input for Apex in Steam settings

Quick Commands

AIM + PS/XBOX Button Open the Mods Menu
AIM + SHARE/VIEW Turn off the script entirely
RIGHT / LEFT (in menu) Navigate between mods
UP / DOWN (in menu) Activate or deactivate a mod
X / A (in menu) Enter a mod's sub-menu
AIM + ARROWS (in menu) Change mod values
SQUARE / X (in menu) Change values inside certain mods

Troubleshooting

If your anti-recoil feels off or isn't engaging, check these common fixes:

  • Make sure Crouch Shot mod is off — it can interfere with recoil control when set wrong
  • Verify your controller is plugged directly into the Zen (not wirelessly paired to the console)
  • Set in-game Vibration to Default — the script uses rumble feedback for detection
  • Make sure you've entered your actual in-game sensitivity values in the Sensitivity Mod
